# Frontend

Aplicación Vue 3 + TypeScript con Vite, servida por nginx en producción.

La puesta en marcha, la arquitectura y la documentación del proyecto están en el
[README principal](../README.md). Los tokens, la tipografía, el movimiento y las
reglas de accesibilidad del sistema de diseño están en [DESIGN.md](DESIGN.md).

```bash
pnpm dev         # Vite en modo dev (dentro del contenedor)
pnpm type-check  # vue-tsc
pnpm build       # type-check + build de producción
```
